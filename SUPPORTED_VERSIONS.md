# Supported Versions

The following table lists which versions of AraNorm currently receive security updates and bug fixes.

| Version | Python Support         | Status              | End of Support |
|---------|------------------------|---------------------|----------------|
| 1.2.x   | 3.9 · 3.10 · 3.11 · 3.12 · 3.13 | ✅ **Active**   | TBD            |
| 1.1.x   | 3.9 · 3.10 · 3.11      | 🔒 Security only    | 2026-01-01     |
| 1.0.x   | 3.9 · 3.10             | ❌ End of Life      | 2025-07-01     |
| < 1.0   | —                      | ❌ End of Life      | —              |

## Policy

- **Active**: Receives bug fixes, security updates, and new features.
- **Security only**: Receives critical security patches only. No new features.
- **End of Life**: No updates. Upgrade to a supported version.

## Python Version Support

AraNorm follows [NEP 29](https://numpy.org/neps/nep-0029-deprecation_policy.html) for Python version support. A Python version is supported for **42 months** after its initial release.

| Python | Minimum AraNorm |
|--------|----------------|
| 3.9    | 1.0.0          |
| 3.10   | 1.0.0          |
| 3.11   | 1.1.0          |
| 3.12   | 1.2.0          |
| 3.13   | 1.2.0          |
